# JC Response 安装／升级提示词

请在 Windows WorkBuddy 桌面端直接完成 JC Response 安装接入。程序来自我给出的已解压目录。没有目录时只问这个路径，不扫描全盘。本提示词对应程序 1.2.0、response_flow/1.1、资料修订 r1，不代表重新编译。

## 固定边界

只能执行以下两个产品命令，不附加 source/target/force 等参数，不使用其他产品或开发命令：

```text
<我给出的已验证解压目录>\bin\JC_response.exe --install-user --json
%LOCALAPPDATA%\Programs\JC_response\bin\JC_response.exe --configure-workbuddy --json
```

可以进行必要的文件存在性、哈希、目录、配置差异检查和私有备份。不得搜索 PATH、进入开发仓库、读取另一套 .env/数据库/凭证、回退全局 jctrans 或 Python。不得提权、关闭防护或绕过权限拒绝。不得执行开通、登录、退出、提额、清零命令，或修改授权和信任文件。

## 顺序

1. 确认当前为 Windows 本机 WorkBuddy 可执行模式。Ask、WSL、远程不满足时停止。使用客户端实际显示的用户级配置位置，不新建第二份配置。
2. 核对给定根目录的三个 bin/ 产品 EXE、VERSION、RELEASE-METADATA.json、SHA256SUMS.txt。先用另行提供的发布 ZIP 哈希核对原 ZIP，再核对包内文件完整性和路径安全。没有可信外部校验值、哈希不符或文件缺失时停止。内部清单不是来源身份凭证。
3. 已有安装位于当前用户 `%LOCALAPPDATA%\Programs\JC_response`。只读比较版本和完整运行文件；更高版本、未知来源、重解析点或混入用户数据时停止，不自动卸载、清理或降级。
4. 让本人保存任务、停用 JC 连接并正常关闭目标程序；不强杀 WorkBuddy。当前客户端占用无法解除时，停止并由 Cursor 在 WorkBuddy 退出后操作。先在 Git 之外私有备份旧程序与配置，不输出内容。产品数据目录原位保持，不为升级先退出 JC 登录。
5. 执行第一条安装命令，同时检查退出码和 JSON。只接受 installed/upgraded/already_installed；target_in_use、target_has_data、conflict 或其他状态停止。失败可能已经部分复制，不根据退出码 0 或 changed=false 宣布成功。
6. 比较正式目录全部 bin/ 文件，再比较说明、Skill、VERSION 和元数据。already_installed 不证明这些都已更新。运行文件不一致则停止；仅资料不同则报告 metadata_refresh_required（流程标签，不是宣称程序有这个返回值），交维护者按升级说明精确刷新。本提示词不得通过手工复制绕过安装命令。
7. 全部核对后执行第二条配置命令。只接受 configured/already_configured；conflict、install_required 或未知状态立即停止。不得覆盖整份 mcp.json、删除服务器、写 token/headers/Cookie 或伪造信任。仅更新 jc-response：stdio、正式 jctrans-mcp.exe 路径、空 args。scys-mcp 等其他项和未知字段保持不变；ZIP 路径不是 MCP url。
8. 不修改 mcp-approvals.json 或任何审批记录。本人完成 Trust/启用并新建会话。不能把配置写入当成客户端已经读取。按本包 Skill 核对工具集合，不再要求恰好两个工具。
9. 新会话只调用一次 jctrans_status；确认实际 capabilities.contract_version=response_flow/1.1。不得调用读取、保存、导出，也不得运行 status --verify。业务读取消耗预算，同批保存/导出不增加 JC 请求但写本地文件；安装验收都不做。
10. 需要登录时，只指引本人在产品窗口登录自己的 JC 账号；密码和验证码在 JC 页面由本人输入。需要范围开通时，转述范围说明，由本人在窗口确认。你不得代开通、代点或写授权文件。旧有效 Token 不能替代范围同意；不得为测试主动 logout。
11. 核对客户端实际加载的 jc-response-preview Skill 与本包一致；文件在包内不等于已生效。旧规则冲突就停止业务操作，定向说明，不自动删除其他 Skill。

分别报告程序、资料、MCP 配置、本人信任、实际 Skill、登录和范围状态，使用 PASS/FAIL/BLOCKED/NOT_RUN。没有完成的步骤如实标明。只在文件核对、配置、本人信任、新会话连接与状态都通过后报告连接器安装完成；登录和范围状态单列。不回显秘密、完整配置、真实回盘或备份内容。
