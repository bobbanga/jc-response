# JC回盘助手：使用条件与能力说明

## 产品定位

中文名：JC回盘助手。英文名：JC Response Assistant。
安装接入 · 上手教学 · 回盘整理。

用自然对话读取、核对自己 JC 账号的回盘，并将同一批导出为固定 30 列中文 CSV。用户只需认识一个助手，不必先理解安装 Skill 与业务工具的拆分。

## 当前支持

Windows x64 本机、Edge、WorkBuddy 桌面端的本地文件/命令能力与本地 stdio MCP。没有对应发行包或实际验收时，不宣称 macOS、Linux、云端宿主或其他 AI 客户端已支持。

技能 0.2.3 配套程序 1.3.0、资料修订 r2；运行包身份以 `runtime-pin.json` 为准。本次仅优化展示与使用引导，没有改变安装脚本、运行包、产品工具、业务规则或预算。

## 费用

本版本的 Skill 和配套公开运行包按免费分享定位提供，不收取本助手月订阅费。JC 服务、WorkBuddy/其他 AI 客户端、模型套餐及网络使用的第三方费用由各服务方另行规定，不能理解为所有第三方服务免费。

发布者需要在开放平台的付费设置中亲自选择“免费”；本文和 ZIP 不会修改后台价格。

## 首次使用

先检查已有安装，缺安装再征得同意后从固定 GitHub Release 获取运行组件。运行包约 122 MB，未签名、为预发布版本；不关闭系统防护、不自动提权。旧安装符合已审核升级身份才升级；未知来源、文件占用或配置冲突准确停止。

程序安装、MCP 配置、客户端信任、JC 登录、首次范围确认分别核验。本人完成信任、JC 页面认证及范围开通；有效范围内日常读取不要求逐批打开许可窗口。升级不得重置凭证、授权、预算或业务数据。

## 读取、导出与数据边界

按用户明确数量读取，单次 1–20 条、1 页，沿用产品累计预算。清单读取用 `list_only`；用户明确要求带详情的业务表时用 `api_full`。查看、保存或导出同一批不会再访问 JC；保存快照与导出 CSV 是不同的本地写入动作。

中文导出 schema 为 `JC_response_business/1.0`。固定 30 列不保证字段全部有值；原始来源不足、字段隐藏或含义未确认时留空并记录原因。不猜港口、币种、报价、有效期或联系人。

JC 凭证由本地产品持有，不写入 Skill 或 MCP 配置。回盘字段会交给当前 AI 客户端，可能由云端模型处理；使用前应确认自己的业务数据可以交给所选客户端。不上传真实 CSV、业务库或凭证到公开仓和市场展示。

## 不提供的能力

不生成最终报价、不应盘提交、不发送外部消息、不作危险品接载决定或商业承诺；不采集 DOM 联系人，不写飞书，不调度或推送，不自动连续采集。MCP 不提供范围开通、提额或清零工具。失败不转用开发 CLI、另一套凭证或网页抓取。
